# Synergia Docs

> Documentación técnica oficial de Synergia, una plataforma de cómputo distribuido voluntario y centralizado. Cualquier usuario publica tareas costosas como repositorios de GitHub y una red de nodos voluntarios (workers) las procesa en contenedores Docker aislados, con resultados verificados por consenso. Los workers ganan créditos internos proporcionales al coste real de cómputo y los usan para publicar sus propias tareas. / Official technical documentation for Synergia, a voluntary, centralized distributed computing platform with cross-verified results and an internal credit economy.

Notas clave para entender el proyecto:

- Tres roles: publicador (publica la tarea apuntando a un repositorio público de GitHub), worker (ejecuta bloques de trabajo localmente en Docker) y servidor (orquesta colas, verifica resultados y lleva el libro de créditos).
- Las tareas son agnósticas al lenguaje: se empaquetan con un `Makefile` (contrato `setup`/`run`/`clean`) y un manifiesto `config.toml`.
- Stack del backend: FastAPI (API REST en el puerto 8000 y API WebSocket en el 8001), RabbitMQ, Oracle Database Free con Blockchain Tables y Prometheus/Grafana.
- Cliente: paquete Python `synergia` (PyPI), comando `synergia`; requiere Python >= 3.10, Docker y `perf`.
- Código: servidor https://github.com/yagomilenio/synergia-server y cliente https://github.com/yagomilenio/synergia-client (licencia GPL-3.0).
- La documentación está disponible en español (raíz) y en inglés (prefijo `/en/`).
- Especificación OpenAPI de la API REST: https://yagomilenio.github.io/synergia-docs/openapi.json

## Visión General

- [Introducción a Synergia](https://yagomilenio.github.io/synergia-docs/docs/introduccion/): Qué es Synergia: red de cómputo distribuido voluntario con verificación e incentivos económicos; roles de publicador, worker y servidor.
- [¿Por qué Synergia?](https://yagomilenio.github.io/synergia-docs/docs/por-que-synergia/): Comparativa frente a BOINC, Folding@Home, SETI, Golem Network, MPI, Hadoop, Spark y sistemas de CI.
- [Primeros Pasos](https://yagomilenio.github.io/synergia-docs/docs/primeros-pasos/): Despliega el servidor con Docker Compose y conecta un nodo cliente en menos de 5 minutos.
- [Configuración del Servidor](https://yagomilenio.github.io/synergia-docs/docs/configuracion-servidor/): Variables de entorno, servicios de docker-compose, puertos y troubleshooting del backend.
- [Configuración del Cliente](https://yagomilenio.github.io/synergia-docs/docs/configuracion-cliente/): Requisitos (Python >= 3.10, Docker, perf), ficheros de configuración local y estructura del proyecto.
- [Caso de Uso Completo](https://yagomilenio.github.io/synergia-docs/docs/caso-de-uso/): Flujo de principio a fin: un publicador lanza una tarea, un worker la procesa y cobra créditos.

- [Arquitectura del Sistema](https://yagomilenio.github.io/synergia-docs/docs/arquitectura/): API REST (FastAPI), API WebSocket, RabbitMQ, Oracle DB y decisiones tecnológicas.
- [Patrones de Diseño](https://yagomilenio.github.io/synergia-docs/docs/patrones-de-diseno/): Productor-consumidor, fachada, singleton, estrategia y decisiones de diseño del proyecto.
- [Flujo de Tareas](https://yagomilenio.github.io/synergia-docs/docs/flujo-de-tareas/): Ciclo de vida: publicación, segmentación, distribución, ejecución local y verificación con liquidación.
- [Internals del Worker](https://yagomilenio.github.io/synergia-docs/docs/worker-aislamiento/): Sandboxing con Docker, wrappers en C, políticas de red con iptables y medición de rendimiento.
